Política de Privacidad de ThaliraBot

ThaliraBot no recopila información personal de los usuarios. Los datos manejados (mensajes, roles, comandos) se usan únicamente para la funcionalidad del bot dentro de Discord.

Uso de datos

  • No se almacenan mensajes privados ni información sensible.
  • Los registros de actividad se limitan a estadísticas internas del bot.

Contacto

Para cualquier consulta, contacta a Shadowpiki en Discord.
