Política de Privacidad / Privacy Policy

1. Introducción / Introduction

La privacidad de los usuarios es importante. Esta política explica qué datos maneja ThaliraBot y cómo se utilizan. User privacy is important. This policy explains what data ThaliraBot handles and how it is used.

2. Datos recopilados / Data Collected

  • Roles de usuarios (VIP y normales). User roles (VIP and regular).
  • Configuraciones de servidor y permisos. Server configurations and permissions.
  • Comandos ejecutados y búsquedas en internet. Executed commands and internet searches.
  • No se almacenan mensajes privados ni información sensible. Private messages or sensitive information are not stored.

3. Uso de datos / Data Usage

Los datos se usan exclusivamente para: Data is used exclusively for:

  • Ejecutar las funciones del bot. Executing bot functions.
  • Administrar servidores de forma eficiente. Efficient server administration.
  • Mejorar la experiencia de los usuarios. Improving user experience.

4. Compartición de datos / Data Sharing

ThaliraBot no comparte información con terceros. Toda la actividad se limita al entorno de Discord. ThaliraBot does not share information with third parties. All activity is limited to the Discord environment.

5. Seguridad / Security

Se aplican medidas técnicas para proteger la información procesada por el bot. Sin embargo, ningún sistema es 100% seguro. Technical measures are applied to protect information processed by the bot. However, no system is 100% secure.

6. Jurisdicción / Governing Law

Esta política se rige por las políticas oficiales de Discord aplicables a bots. This policy is governed by Discord’s official policies applicable to bots.

7. Cambios en la política / Policy Changes

La política puede actualizarse en cualquier momento. Los cambios se publicarán en esta página. The policy may be updated at any time. Changes will be published on this page.
