Política de Privacidad de ThaliraBot

1. Introducción

La privacidad de los usuarios es importante. Esta política explica qué datos maneja ThaliraBot y cómo se utilizan.

2. Datos recopilados

  • ThaliraBot no almacena mensajes privados ni información sensible.
  • Los datos procesados se limitan a comandos, roles y configuraciones necesarias para el funcionamiento del bot.
  • Se pueden registrar estadísticas internas de uso para mejorar el servicio.

3. Uso de datos

Los datos recopilados se utilizan exclusivamente para:

  • Ejecutar las funciones del bot dentro de Discord.
  • Mejorar la experiencia de los usuarios mediante actualizaciones.
  • Garantizar la seguridad y estabilidad del servicio.

4. Compartición de datos

ThaliraBot no comparte información con terceros. Toda la actividad se limita al entorno de Discord.

5. Seguridad

Se aplican medidas técnicas para proteger la información procesada por el bot. Sin embargo, ningún sistema es 100% seguro.

6. Cambios en la política

La Política de Privacidad puede actualizarse en cualquier momento. Los cambios se publicarán en esta página y se considerarán aceptados al continuar usando el bot.

7. Contacto

Para consultas relacionadas con la privacidad, contactar a Shadowpiki en Discord.
