Condiciones de Servicio de ThaliraBot

1. Introducción

Estas Condiciones de Servicio regulan el uso de ThaliraBot en la plataforma Discord. Al añadir el bot a un servidor, el usuario acepta cumplir con estas normas.

2. Uso permitido

  • El bot puede ser utilizado en servidores personales, comunitarios o comerciales.
  • Está prohibido el uso para spam, acoso, difusión de contenido ilegal o actividades que infrinjan las normas de Discord.
  • El usuario es responsable de la configuración y permisos otorgados al bot dentro de su servidor.

3. Limitaciones de responsabilidad

El equipo de desarrollo no se hace responsable de:

  • Pérdida de datos ocasionada por el uso del bot.
  • Mal uso por parte de administradores o miembros del servidor.
  • Interrupciones del servicio debido a mantenimiento o fallos técnicos.

4. Modificaciones

Las Condiciones de Servicio pueden actualizarse en cualquier momento. Los cambios serán publicados en esta página y se considerarán aceptados al continuar usando el bot.

5. Terminación

El equipo de desarrollo se reserva el derecho de retirar el acceso al bot en cualquier servidor que incumpla estas condiciones.

6. Contacto

Para consultas o soporte, contactar a Shadowpiki en Discord.
